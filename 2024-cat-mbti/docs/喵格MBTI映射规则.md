## 一、四维度行为观察清单

### 维度 1 · E（外向）vs I（内向）
**观察重点**：社交性、对外部刺激的反应

| 行为信号 | E 加分 | I 加分 |
| --- | --- | --- |
| 主动靠近镜头 / 人 | +2 | — |
| 对陌生声音 / 物体反应 | 兴奋接近 +2 | 躲藏退缩 +2 |
| 叫声频率 | 频繁 +1 | 几乎不叫 +1 |
| 活动范围 | 大范围探索 +1 | 固定小角落 +1 |
| 被抚摸反应 | 蹭手撒娇 +1 | 闪躲 / 警惕 +1 |

**判定**：取分数高的一方；分差 ≤1 时默认 I（猫普遍偏 I，向 I 倾斜更准）

## 三、打分算法伪代码

```python
def analyze_cat_mbti(behaviors: dict) -> str:
    """
    behaviors: 视频分析输出的行为信号字典
    return: 4 字母 MBTI 类型
    """
    # 维度 1: E / I
    e_score = sum([
        behaviors.get('approach_camera', 0) * 2,
        behaviors.get('excited_to_stimuli', 0) * 2,
        behaviors.get('vocal_frequency', 0),
        behaviors.get('exploration_range', 0),
        behaviors.get('enjoy_petting', 0),
    ])
    i_score = sum([
        behaviors.get('hide_from_stimuli', 0) * 2,
        behaviors.get('silent', 0),
        behaviors.get('stay_in_corner', 0),
        behaviors.get('avoid_petting', 0),
    ])
    dim1 = 'E' if e_score > i_score + 1 else 'I'

    # 维度 2/3/4 同理...
    return dim1 + dim2 + dim3 + dim4
```

## 四、使用说明与边界

### 适用范围
- 视频时长建议 10–30 秒，包含猫的多种自然行为
- 单一行为不足以判定，需多信号综合
- 黑客松 demo 阶段：可以人工预标注几只样本猫的"标准答案"，确保现场演示稳定

### 已知局限
- 同一只猫在不同场景下表现差异较大，单次测试结果仅供娱乐
- 幼猫、老猫的行为模式与成年猫差异显著，未来可加入年龄校准
- 多猫家庭中，社交行为信号会失真

### 兜底策略
- 若行为信号不足（如视频太短 / 信息量低），默认输出 **ISFP（文艺猫）**——猫格中最具普适性、用户接受度最高的类型
- 每个维度提供"信心分数"，低于阈值时引导用户重新上传
