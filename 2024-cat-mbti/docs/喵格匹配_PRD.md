## 一、产品定位

### 1.1 一句话定位
**上传你家猫的视频，AI 读懂 TA 的性格，再让 TA 亲口告诉你 TA 是谁、想要怎样被爱。**

### 1.2 三大核心能力
1. **看懂** —— 视频分析出猫的 MBTI 类型（16 型猫格之一）
2. **讲清** —— 给出这只猫的完整性格档案（5 维度详解）
3. **开口** —— 用你家猫的样子，生成对你说话的短视频

### 1.3 背景
- **情感缺口**：铲屎官最大的遗憾是"我家猫如果会说话就好了"——AI 终于能做到
- **MBTI 热度**：年轻用户对 MBTI 自测/互测内容持续买单，且猫 MBTI 比人 MBTI 更具传播性（没人会觉得被冒犯）
- **AI 视频生成成熟**：Gemini 3.1 / Veo 3 / 即梦等已支持参考图保持角色一致
- **抖音生态**：宠物内容是大流量赛道，输出物天然契合短视频分发

### 1.4 目标用户
- **核心**：1-3 岁猫龄铲屎官（最爱秀、情感投射最强）
- **次级**：有意养猫人群、宠物内容消费者、亲友赠礼场景

### 1.5 北极星指标
| 维度 | 指标 |
| --- | --- |
| 情感共鸣 | 视频生成后分享率、二次传播率 |
| 用户粘性 | 同一只猫的复用生成次数 |
| 商业闭环 | "猫亲口推荐"商品的 CTR / GMV |

## 二、核心用户链路

```
上传猫视频 (10-30s)
   ↓
①  AI 视觉模型识别行为信号 + 规则引擎判定 MBTI (5-10s)
   ↓
②  展示猫格档案：性格特质 / 典型行为 / 喜欢 / 讨厌 / 相处 Tips
   ↓
③  LLM 生成对话脚本 → 图生视频：让你家猫"开口"对你说话 (30-90s)
   ↓
分享 / 再生成 / 一键购买"猫亲口推荐"商品
```

**核心交付物**：
- 📋 一份完整的猫格档案（让你瞬间看懂你家猫）
- 🎬 一段 5-15 秒视频（你家猫，用你家猫的样子，对你说话）

## 三、功能模块

### M1 · 上传与 MBTI 分析（底座）

**输入**：10-30 秒猫视频（MP4 / MOV / WebM）

**AI 识别四维度**（基于 20 个行为信号）：
| 维度 | 观察重点 |
| --- | --- |
| E / I | 社交性、对外部刺激的反应 |
| S / N | 注意力对象（眼前事物 vs 抽象/远处） |
| T / F | 情绪表达强度、对人的情感依赖 |
| J / P | 作息规律性、对变动的反应 |

**输出**：
- 16 型猫格之一（如 ENFP "阳光猫"）
- 视频中的高光时刻引用
- 一张关键帧（用作后续视频生成的参考图）

---

### M2 · 猫格档案（情感共鸣层）⭐

**定位**：让用户瞬间感受到「这就是我家猫」的拍案叫绝。

每个 MBTI 类型呈现 5 个维度：

| 维度 | 内容 | 价值 |
| --- | --- | --- |
| ✨ **性格特质** | 3-4 句的整体画像 | 让用户认同"对，就是这样" |
| 🎬 **典型行为** | 2-3 个具体场景化的小动作 | 共鸣点最密集，引发"哈哈我家也是"分享 |
| 💗 **TA 最喜欢** | 铲屎官做什么会让 TA 开心 | 实用价值 + 软性带货钩子 |
| 🚫 **TA 最讨厌** | 雷区清单 | 提升养育水平，强化责任感 |
| 🌱 **相处 Tips** | 针对性养育建议 | 长期价值 + 商品推荐钩子（淡绿色突出） |

**示例（ENFP 阳光猫）**：

> **性格特质**：见谁都贴贴的社牛代表。对世界充满热情，把每天都过成派对。情绪外放、表情丰富、坦率得让人无法不爱。
>
> **典型行为**：
> 🐾 主动凑近镜头 / 客人
> 🐾 尾巴常竖起像感叹号
> 🐾 叫声多变像在和你聊天
>
> **TA 最喜欢**：新朋友、各种玩具轮换、被关注被夸奖
>
> **TA 最讨厌**：长时间独处、被冷处理、单调的环境
>
> **相处 Tips**：它需要的不是"安静"而是"陪伴质量"。互动玩具 + 常带朋友来家里，比任何零食都治愈。

**已实现状态**：16 型完整档案已在 `backend/profiles.py` 中固化。

---

### M3 · 对话脚本生成（LLM）

LLM 基于 MBTI 类型 + 猫格档案，生成结构化对话脚本：

```
[场景设定] 一只 ENFP 阳光猫正歪头看着镜头
[语气特征] 热情奔放、跳跃式表达、像撒娇的小孩
[对话内容]
  - 开场: "嘿铲屎的，我又有事要跟你说啦！"
  - 喜欢的行为: "我超爱你下班一进门就喊我名字
  - 想说的话: "你工作太忙啦，多回家陪我玩 5 分钟也好的"
  - 养育建议: "我是 ENFP，多备点互动玩具，
    独处太久我会胡思乱想的"
[动作提示] 镜头慢拉近，猫缓缓转头，尾巴在画面下方轻摆
```

**对话必包含 4 个模块**：
1. 该 MBTI 的**说话方式**（语气）
2. **喜欢主人做什么**
3. **想对主人说的话**（情感钩子）
4. **针对性养育建议**（也是带货钩子）

**资料源**：直接复用 M2 猫格档案数据，保证档案与对话内容一致性。

---

### M4 · AI 视频生成（产品核心亮点）

**输入**：
- 参考图（用户上传猫的关键帧 → 锁定形象）
- 对话脚本（含动作描述）
- MBTI 风格化提示词

**输出**：5-15 秒视频——你家猫的真实形象 + 字幕 + 画外音 + MBTI 风格动作

**关键设计：不做 lip-sync（避坑）**
- 让猫说话不需要嘴动 — 用「云对话」手法
- 表现层：**字幕 + 旁白 + 表情/动作/眼神呼应**
- 避开"猫嘴 + 中文台词"这个目前无成熟方案的领域

**MBTI × 动作映射表（节选）**：

| MBTI | 动作风格 | 镜头建议 |
| --- | --- | --- |
| ENFP 阳光猫 | 主动凑镜头、尾巴竖起、表情夸张 | 中景，逐渐拉近 |
| INTJ 战略家猫 | 高处俯视、目光锐利、几乎不动 | 仰角，远景 |
| INFP 艺术家猫 | 趴窗台、目光柔和、缓慢眨眼 | 侧光，柔光 |
| ESTP 冒险家猫 | 跳跃、飞奔、镜头跟随 | 动感平移 |
| ISFJ 居家猫 | 蹭主人腿、缓慢蹲下 | 俯视，温暖光 |

---

### M5 · 视频呈现 / 分享 / 衍生

- **全屏竖版播放**（与抖音原生体验一致）
- **双击屏幕**触发"猫舔屏"特效
- **一键分享抖音**，自动带话题 `#我家猫开口说话`
- **截屏分享朋友圈**，自动加水印"听我家球球说……"
- **再生成**：换一段新对话（不同话题）
- **猫亲口推荐**：视频里提到的商品（玩具/猫粮/猫窝）一键跳转抖音商城

## 四、Demo 演示路径

### 4.1 现场脚本（3 分钟）

| 时长 | 动作 | 话术要点 |
| --- | --- | --- |
| 0:00-0:30 | 开场抛钩子 | "如果你家猫真的能开口说话，TA 会说什么？" |

- **加分**：现场再生成一段（如果时间允许）
- **生成中**：流式展示 → MBTI 报告卡 → 猫格档案 → 对话预告，避免冷场

### 5.2 已落地链路
```
用户上传视频 → FastAPI /analyze
   → OpenCV 抽 6 帧 → 豆包视觉模型 → 20 信号 JSON
   → 规则引擎 → MBTI 类型
   → 拼装猫格档案 (profiles.py) → 返回前端
   → 前端结果页 + 猫格档案 section 渲染
```

### 5.3 视频生成 Prompt 模板（M4 落地用）

```
[Reference Image] <用户上传猫的关键帧>
[Duration] 8 seconds
[Camera] Medium shot, eye-level, slow push-in
[Lighting] Warm golden hour, soft

[Subject] A <品种描述> cat with the same appearance as reference image.
The cat has an ENFP personality (sunny, outgoing, expressive).

[Action] The cat slowly tilts its head toward camera, eyes wide and curious.
Tail flicks gently at the bottom of frame. Subtle nose twitch at 3s.
No mouth movement — emotional expression through eyes and posture.

[Style] Cozy, intimate, lifestyle photography aesthetic.
Slight grain for film texture.

[Avoid] Mouth opening/talking motion, sudden movements, multiple cats.
```

### 5.4 流式体验设计（覆盖 30-90s 生成等待）
1. **0-10s**：展示 MBTI 报告卡（让用户阅读）
2. **10-30s**：滚动展示猫格档案 5 个维度（密集信息消化等待时间）
3. **30-60s**：显示对话脚本预告（文字版先出）
4. **60-90s**：视频生成完毕 → 自动播放 + 震动提示

## 七、风险与简化策略

| 风险 | 应对 |
| --- | --- |
| 视频生成耗时长 | 预生成兜底 + 流式体验（猫格档案天然填充等待时间） |
| 猫形象一致性差 | 图生视频 + 参考图锁定 + Prompt 强约束 |
| MBTI 动作不稳定 | Prompt 多轮调优 + 离线挑选高质量成片 |
| 用户上传视频质量差 | 上传时教育"光线清晰、单只猫、中景"，质量不够时提示重拍 |
| 内容同质化（多次生成相似） | LLM 加入"今日变量"（天气、星期、节日）保证新鲜 |
| Gemini 3.1 调用限额 | 备选 Veo 3 / 即梦 / Kling 切换 |
| MBTI 测试娱乐性 vs 科学性 | 明确定位为娱乐向产品，加免责声明 |
